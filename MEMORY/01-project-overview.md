# 01 — Project overview

## The game
- **Title:** *Unsent* (repo name `ember-of-memories-`, first commit was called "Ember Letters").
- **Genre:** short first-person narrative / walking-sim with small mini-games ("memories").
- **Premise:** a grown child returns at night, in snow, to the childhood cottage. A glowing
  **Ember** companion leads them room to room. Each room holds a frozen, grey memory; solving
  its small mini-game restores it (colour + warmth return). The twist: the player is the child
  who left and never came back; a letter reveals the parent "kept the fire going".
- **Visual language:** world starts desaturated (`world_sat` 0.3), colour drains/returns with the
  story; memory people are faint ember-gold ghosts with pixelated faces; film-grain/vignette look.
- **Audio language:** solo piano on the title only → broken music-box theme in play → full theme at the ending.

## Folder map
```
project.godot            engine config: autoload, input map, layer names, shader global world_sat
scenes/
  main.tscn              root: GameDirector + every system (see 02-architecture)
  level/house_level.tscn GENERATED by tools/level_builder.gd, then hand-editable (~290 KB)
  player/ characters/    player body+camera, Ember companion
  memories/              one scene per story step (7)
  objects/               reusable interactables & props (doors, gate, scarf rack, puzzle...)
  systems/               HUD, ScreenEffects, Snowfall, Sound (autoload), TitleSequence
scripts/                 mirrors scenes/ (one script per node) + utils/ + dev/
shaders/                 8 .gdshader files (2 currently unused — see 05)
materials/               .tres materials; materials/level/ written by level_builder
assets/                  audio, characters (glb), mixamo (fbx), polyhaven (gltf), sketchfab (glb),
                         "stylised assets" (Quaternius MegaKits, note the SPACE in the folder name), textures
tools/                   headless one-off scripts (extends SceneTree) — never run in-game
MEMORY/                  this knowledge base
```

## How to run
```powershell
& "C:\Program Files\Godot\Godot.exe" --path .                       # play
& "C:\Program Files\Godot\Godot.exe" --path . --editor              # editor
& "C:\Program Files\Godot\Godot.exe" --headless --path . -- --storytest   # automated story test
```
Other test flags: `--walktest` (add `--gate` to start outside), `--doortest`. Output lines starting
with `TEST` are results; each prints PASS/FAIL. All three passed headless at commit 7509065.
