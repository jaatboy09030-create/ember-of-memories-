# IdiotHandOffGuide — "Worn camera" (body-cam blend) for *Unsent*, phase 1

## A. Execution contract

**Outcome.** The first-person camera gets a body-cam / found-footage feel blended into the game's existing quiet, melancholic look. This is not a copy of *Bodycam* or *Unrecord*: there is no chest mount, no extreme fisheye and no police HUD.

**This phase adds:**
1. A gentle lens bend (barrel distortion, cropped so there are no black edges) with colour fringe toward the edges.
2. Sensor grain that is stronger in dark areas.
3. Slow auto-exposure adaptation.
4. A hand-held drift on the camera.
5. A spring sway that lags behind starting and stopping.
6. A bank into turns.
7. Uneven footsteps.
8. Noise-based shake (replacing `randf` jitter).
9. One shared `CameraComfort` resource, so every effect can be scaled to 0 for accessibility.

**Scope.** Exactly the files in section C. No options-menu UI, no motion-blur addon, no REC/timestamp overlay. Those are phase 2 and need the owner's decision (listed in section G).

### S3 — Replace entire file `shaders/camera_fx.gdshader`

Prerequisite: S0 baseline matched. The new shader keeps every uniform name the current one has (`vignette`, `grain`, `aberration`, `warmth`, `faces`, `face_count`, `world_sat`), so `screen_effects.tscn` and the existing tweens keep working.

```glsl
shader_type canvas_item;
// FILM / WORN-CAMERA LOOK drawn over the 3D view (ScreenEffects > FilmLook).
// Values are driven by scripts/systems/screen_effects.gd.
// Order: lens bend -> face mosaics -> colour fringe -> frozen-memory grey -> vignette
//        -> warm/cold tint -> sensor grain.
uniform sampler2D screen_tex : hint_screen_texture, filter_linear;
uniform float vignette = 0.32;
uniform float grain = 0.03;
uniform float aberration = 0.0012;
uniform float warmth = 0.0; // -1 cold .. 1 warm tint
// Face mosaics: xy = centre (px), z = half size (px), w = 1 active.
// Given in the FLAT (unbent) screen pixels, as Camera3D.unproject_position returns them.
uniform vec4 faces[4];
uniform int face_count = 0;
uniform float world_sat = 1.0;
// Lens bend (Brown-Conrady radial k1, k2). 0 = flat image. The bent image is scaled so the
// corners stay filled: no black or smeared edges, at the cost of a slight zoom.
uniform float lens_k1 : hint_range(0.0, 0.5) = 0.0;
uniform float lens_k2 : hint_range(0.0, 0.5) = 0.0;
// Colour fringe that grows toward the edges of the lens.
uniform float lens_fringe : hint_range(0.0, 0.05) = 0.0;
// 0..1: extra grain in dark areas (cheap camera sensor).
uniform float shadow_noise : hint_range(0.0, 1.0) = 0.0;

// For a pixel of the bent picture, where to read in the flat render.
vec2 lens_uv(vec2 uv, float aspect) {
	vec2 p = (uv - 0.5) * vec2(aspect, 1.0);
	float r2 = dot(p, p);
	float rc2 = 0.25 * (aspect * aspect + 1.0); // squared distance to a corner
	float s = 1.0 + lens_k1 * rc2 + lens_k2 * rc2 * rc2;
	p *= (1.0 + lens_k1 * r2 + lens_k2 * r2 * r2) / s;
	return p / vec2(aspect, 1.0) + 0.5;
}

void fragment() {
	vec2 res = 1.0 / SCREEN_PIXEL_SIZE;
	vec2 uv = lens_uv(SCREEN_UV, res.x / res.y);
	vec2 px = uv * res;
	for (int i = 0; i < 4; i++) {
		if (i >= face_count) break;
		vec4 f = faces[i];
		if (f.w > 0.5 && abs(px.x - f.x) < f.z && abs(px.y - f.y) < f.z * 1.15) {
			float cell = max(f.z / 3.5, 4.0);
			vec2 q = (floor((px - f.xy) / cell) + 0.5) * cell + f.xy;
			uv = q / res;
		}
	}
	vec2 d = SCREEN_UV - 0.5;
	vec2 dl = uv - 0.5;
	vec2 shift = d * aberration * 2.0 + dl * lens_fringe * dot(dl, dl) * 4.0;
	float r = texture(screen_tex, clamp(uv + shift, vec2(0.0), vec2(1.0))).r;
	float g = texture(screen_tex, uv).g;
	float b = texture(screen_tex, clamp(uv - shift, vec2(0.0), vec2(1.0))).b;
	vec3 c = vec3(r, g, b);
	// frozen memory: grey, except bright light sources keep their warmth
	float lum = dot(c, vec3(0.299, 0.587, 0.114));
	float keep = max(world_sat, smoothstep(0.55, 1.1, lum));
	c = mix(vec3(lum), c, clamp(keep, 0.0, 1.0));
	float v = smoothstep(0.9, 0.25, length(d * vec2(1.0, 0.8)));
	c *= mix(1.0 - vignette, 1.0, v);
	c *= mix(vec3(1.0), warmth > 0.0 ? vec3(1.06, 1.0, 0.9) : vec3(0.92, 0.97, 1.06), abs(warmth));
	// sensor grain on the sensor itself (flat screen coords), stronger in the dark
	float n = fract(sin(dot(SCREEN_UV * (TIME + 1.0) * 61.0, vec2(12.9898, 78.233))) * 43758.5453);
	float lum2 = dot(c, vec3(0.299, 0.587, 0.114));
	c += (n - 0.5) * grain * (1.0 + shadow_noise * 1.5 * (1.0 - smoothstep(0.0, 0.5, lum2)));
	COLOR = vec4(c, 1.0);
}
```

**Postcondition:**
- The file contains `lens_uv` and `filter_linear;`.
- With `lens_k1 = lens_k2 = lens_fringe = shadow_noise = 0`, the maths reduces to the old shader. The only differences are that grain is keyed on `SCREEN_UV` and there is no mip filter, neither of which is visible.

### S4 — Replace entire file `scripts/player/player_camera.gd`

Prerequisites: S2b (`CameraComfort` must be registered).

**Kept public API** (used by memories, title and dev tests), with the same names and behaviour:
- `bob_walk`, `bob_jog`, `breathing_sway`, `default_fov`, `cinematic`, `look_target`, `shake`
- `glance()`, `add_shake()`, `reveal_face()`, `focus()`

**Changed:**
- `default_fov` 70 → 74, which compensates the roughly 10 % crop of the lens.
- New `comfort` and `apply_comfort()`.
- Shake is now smooth noise instead of white noise.

```gdscript
class_name PlayerCamera
extends Camera3D
## PLAYER CAMERA: first-person view with a heavy, slow "worn camera" feel:
## head bob with uneven steps, breathing, a slow hand-held drift, a sway that lags behind
## starting and stopping, a bank into turns, smooth noise shake, and glancing toward things
## you touch. Brightness slowly adapts between dark and bright places (auto exposure).
## In cutscenes set `cinematic = true`: the camera stops following the head and the
## cutscene moves it freely; if `look_target` is set it keeps looking at that point, and
## drift + shake still play on top so cutscenes feel hand-held too.
##
## How to change it: the @export values below (grouped in the Inspector). Overall strength
## and accessibility: settings/camera_comfort.tres. focus(dist) for depth of field.
## The lens bend itself is a screen effect (ScreenEffects), not this camera.

@export var bob_walk := 0.032
@export var bob_jog := 0.045
@export var breathing_sway := 0.004
## Vertical field of view in degrees. A bit wider than before (70) because the screen lens
## effect crops about 10 % of the picture to bend it.
@export var default_fov := 74.0
## Shared strength sliders (motion / shake / exposure). Empty = everything at full.
@export var comfort: CameraComfort

@export_group("Worn camera sway")
## Start/stop sway spring speed in Hz (lower = looser, floatier).
@export var sway_frequency := 2.2
## Spring damping: 1 = settles with no wobble, lower = a little overshoot.
@export_range(0.1, 1.5) var sway_damping := 0.55
## Tilt (radians) per m/s² of speeding up or slowing down.
@export var accel_tilt := 0.004
## Largest start/stop tilt, radians.
@export var max_accel_tilt := 0.035
## Roll (radians) per radian/second of turning: the camera banks into turns.
@export var turn_roll := 0.012
## Largest turn bank, radians.
@export var max_turn_roll := 0.03
## Slow hand-held drift, degrees.
@export var drift_degrees := 0.35
## Drift speed (higher = more nervous hands).
@export var drift_speed := 0.18
## One foot lands a little heavier than the other (0 = identical steps).
@export_range(0.0, 1.0) var step_asymmetry := 0.25

@export_group("Shake")
## Shake rotation in degrees at shake = 1.
@export var shake_degrees := 1.8
## Shake position jolt in metres at shake = 1.
@export var shake_offset := 0.02
## How fast the shake jitters (noise speed).
@export var shake_speed := 14.0

@export_group("Exposure")
## How strongly brightness adapts (0 = off). Keep low: the night must stay dark.
@export_range(0.0, 1.0) var exposure_adapt_strength := 0.2
## How fast it adapts (lower = slower, more like a cheap camera).
@export var exposure_adapt_speed := 0.8

## true = a cutscene drives the camera (position/rotation are left alone by this script).
var cinematic := false
## While cinematic, look at this point every frame (Vector3.INF = don't).
var look_target := Vector3.INF

var shake := 0.0
var _roll := 0.0
var _settle := 0.0
var _time := 0.0
var _glance_point := Vector3.INF
var _glance_amount := 0.0
var _noise := FastNoiseLite.new()
var _last_velocity := Vector3.ZERO
var _last_yaw := 0.0
var _has_last_yaw := false
var _sway := Vector2.ZERO  # x = pitch tilt, y = roll tilt (radians), spring position
var _sway_velocity := Vector2.ZERO
var _turn_bank := 0.0

@onready var player: PlayerBody = get_parent()


func _ready() -> void:
	fov = default_fov
	_noise.noise_type = FastNoiseLite.TYPE_SIMPLEX_SMOOTH
	_noise.frequency = 1.0
	_noise.seed = 7
	apply_comfort()


## Re-read the comfort resource (call after an options menu changes it).
func apply_comfort() -> void:
	var attr := attributes as CameraAttributesPractical
	if not attr:
		return
	attr.auto_exposure_enabled = exposure_adapt_strength > 0.0 and (comfort == null or comfort.exposure_adapt)
	attr.auto_exposure_scale = exposure_adapt_strength
	attr.auto_exposure_speed = exposure_adapt_speed


func _physics_process(delta: float) -> void:
	_time += delta
	if player.just_stopped:
		_settle = 1.0  # tiny dip as you come to rest
	_settle = move_toward(_settle, 0.0, delta * 2.5)
	_roll = lerpf(_roll, -player.strafe * 0.025, clampf(6.0 * delta, 0.0, 1.0))
	_update_sway(delta)
	if cinematic:
		if look_target != Vector3.INF:
			look_at(look_target)
			var h := _handheld_rotation()
			rotate_object_local(Vector3.UP, h.y)
			rotate_object_local(Vector3.RIGHT, h.x)
			rotate_object_local(Vector3.BACK, h.z)
		return
	var heavy_foot := int(floorf(player.step_phase / PI)) % 2 == 1
	var bob := -absf(sin(player.step_phase)) * (bob_jog if player.is_jogging else bob_walk) \
		* (1.0 + (step_asymmetry if heavy_foot else 0.0))
	bob += sin(_time * 1.3) * breathing_sway - sin(_settle * PI) * 0.02
	_follow_head(bob * _motion())


## Start/stop sway (a spring that lags behind changes of speed) and the bank into turns.
func _update_sway(delta: float) -> void:
	if delta <= 0.0:
		return
	var v := player.velocity
	var acc := (v - _last_velocity) / delta
	_last_velocity = v
	var fwd := player.facing()
	var right := fwd.cross(Vector3.UP).normalized()
	var target := Vector2(
		clampf(-acc.dot(fwd) * accel_tilt, -max_accel_tilt, max_accel_tilt),
		clampf(-acc.dot(right) * accel_tilt, -max_accel_tilt, max_accel_tilt))
	var w := TAU * sway_frequency
	_sway_velocity += (-2.0 * sway_damping * w * _sway_velocity - w * w * (_sway - target)) * delta
	_sway += _sway_velocity * delta
	var yaw := player.pivot.rotation.y
	if not _has_last_yaw:
		_last_yaw = yaw
		_has_last_yaw = true
	var yaw_rate := angle_difference(_last_yaw, yaw) / delta
	_last_yaw = yaw
	var bank := clampf(yaw_rate * turn_roll, -max_turn_roll, max_turn_roll)
	_turn_bank = lerpf(_turn_bank, bank, 1.0 - exp(-8.0 * delta))


## Slow hand-held drift plus smooth shake, as (pitch, yaw, roll) in radians.
func _handheld_rotation() -> Vector3:
	var drift := deg_to_rad(drift_degrees) * _motion()
	var t := _time * drift_speed
	var r := Vector3(_noise.get_noise_2d(t, 0.0), _noise.get_noise_2d(t, 50.0), _noise.get_noise_2d(t, 100.0) * 0.6) * drift
	var s := shake * _shake_scale()
	if s > 0.0:
		var ts := _time * shake_speed
		r += Vector3(_noise.get_noise_2d(ts, 200.0), _noise.get_noise_2d(ts, 300.0), _noise.get_noise_2d(ts, 400.0) * 0.5) \
			* deg_to_rad(shake_degrees) * s
	return r


func _follow_head(bob: float) -> void:
	var yaw := player.pivot.rotation.y + PI
	var p := player.pitch
	if _glance_amount > 0.001 and _glance_point != Vector3.INF:
		var d := _glance_point - player.head_position()
		yaw = lerp_angle(yaw, atan2(-d.x, -d.z), _glance_amount)
		p = lerpf(p, atan2(d.y, Vector2(d.x, d.z).length()), _glance_amount)
	var m := _motion()
	var step_roll := sin(player.step_phase) * 0.006 * m
	var idle_roll := sin(_time * 0.7) * 0.003 * m
	var h := _handheld_rotation()
	var roll := (_roll + _sway.y + _turn_bank) * m + step_roll + idle_roll + h.z
	var b := Basis(Vector3.UP, yaw + h.y) * Basis(Vector3.RIGHT, p + h.x + _sway.x * m) * Basis(Vector3.BACK, roll)
	var s := shake * _shake_scale()
	var ts := _time * shake_speed
	var jolt := Vector2(_noise.get_noise_2d(ts, 500.0), _noise.get_noise_2d(ts, 600.0)) * shake_offset * s
	global_transform = Transform3D(b, player.head_position() + player.facing() * 0.12 + Vector3(jolt.x, bob + jolt.y, 0))


func _motion() -> float:
	return comfort.motion if comfort else 1.0


func _shake_scale() -> float:
	return comfort.shake if comfort else 1.0


## Briefly turn the head toward something you interacted with.
func glance(point: Vector3, amount := 0.35) -> void:
	_glance_point = point
	var tw := create_tween()
	tw.tween_property(self, "_glance_amount", amount, 0.35).set_trans(Tween.TRANS_SINE)
	tw.tween_interval(0.6)
	tw.tween_property(self, "_glance_amount", 0.0, 0.8).set_trans(Tween.TRANS_SINE)


func add_shake(amount: float, time_s := 0.5) -> void:
	shake = maxf(shake, amount)
	create_tween().tween_property(self, "shake", 0.0, time_s).set_trans(Tween.TRANS_EXPO).set_ease(Tween.EASE_OUT)


## The ending: let the camera see the body (and the face) for the first time.
func reveal_face() -> void:
	cull_mask = 0xFFFFF


## Depth of field: keep things `dist` metres away sharp. dist <= 0 turns it off.
func focus(dist: float) -> void:
	var attr := attributes as CameraAttributesPractical
	if not attr:
		return
	if dist <= 0.0:
		attr.dof_blur_far_enabled = false
		attr.dof_blur_near_enabled = false
		return
	attr.dof_blur_far_enabled = true
	attr.dof_blur_far_distance = dist + 0.6
	attr.dof_blur_far_transition = maxf(dist * 0.8, 0.8)
	attr.dof_blur_near_enabled = dist > 1.0
	attr.dof_blur_near_distance = maxf(dist * 0.4, 0.1)
	attr.dof_blur_near_transition = 0.3
```

**Design notes the executor must not change:**
- **Rotation is never accumulated without being reset:** `rotate_object_local` only runs right after `look_at()`, which resets rotation every tick. When cinematic mode has no `look_target` (the drawing puzzle), nothing is added, so the camera holds still.
- **`_last_yaw` is set lazily on the first tick.** The parent's `@onready var pivot` is not ready yet when this child's `_ready` runs.
- **Interaction ray stability:** the ray is a child of this camera. Roll does not move a forward ray. Drift is at most about 0.35° (about 7 mm at 1.2 m). Start/stop tilt is capped at 0.035 rad and only happens while speed changes. Dev-test ray checks teleport a standing player, so the tilt is 0 there.

Postcondition: the file contains `func apply_comfort()` and `_handheld_rotation`, and no longer contains `randf_range`.

```gdscript
class_name ScreenEffects
extends CanvasLayer
## SCREEN EFFECTS: the film / worn-camera look drawn over the 3D view
## (shaders/camera_fx.gdshader): a gentle lens bend (barrel distortion, cropped so there are
## no black edges) with colour fringe toward the edges, vignette, sensor grain that is
## stronger in the dark, warm/cold tint, the grey "frozen memory" look, and the pixelated
## faces of the memory figures.
##
## The lens is only on while the player's camera (PlayerCamera) is the active camera. It
## fades out for any other camera (e.g. the drawing puzzle, where the mouse must hit exactly
## what it points at) and is softer while a cutscene drives the player camera.
## The HUD is a higher CanvasLayer, so prompts and captions are never bent.
##
## How to change it: the resting values and the Lens group below; overall strength and
## accessibility in settings/camera_comfort.tres; the shader's own uniforms are on
## FilmLook > Material in the Inspector.
##
## World colour: `world_saturation` (0 grey .. 1 full colour) drives BOTH this screen effect
## and every textured prop (the global shader parameter "world_sat").

@export var resting_vignette := 0.32
@export var resting_aberration := 0.0012
## Film grain amount when comfort.grain = 1.
@export var resting_grain := 0.03
## Faces further away than this are not pixelated.
@export var face_blur_distance := 14.0
## Shared strength sliders (lens / grain). Empty = everything at full.
@export var comfort: CameraComfort

@export_group("Lens")
## Barrel bend (k1). 0 = flat. ~0.1 = gentle worn-camera curve; 0.3+ = fisheye.
@export_range(0.0, 0.5) var lens_bend := 0.1
## Extra bend toward the far corners (k2).
@export_range(0.0, 0.5) var lens_bend_edges := 0.02
## Colour fringe that grows toward the edges.
@export_range(0.0, 0.02) var lens_fringe := 0.003
## Lens strength while a cutscene drives the player camera (PlayerCamera.cinematic).
@export_range(0.0, 1.0) var cinematic_lens_scale := 0.6
## How fast the lens fades in/out when the active camera changes (full strength per second).
@export var lens_fade_speed := 3.0
## 0..1: how much stronger the grain is in dark areas (cheap-sensor noise).
@export_range(0.0, 1.0) var shadow_noise := 0.6

@onready var film_look: ColorRect = $FilmLook
@onready var mat: ShaderMaterial = film_look.material

var world_saturation := 0.3:
	set(v):
		world_saturation = v
		RenderingServer.global_shader_parameter_set("world_sat", v)
		if mat:
			mat.set_shader_parameter("world_sat", v)

var _lens := 0.0  # 0 = no lens .. 1 = full lens, eased toward its target every frame


func _ready() -> void:
	world_saturation = world_saturation
	apply_comfort()


## Re-read the comfort resource (call after an options menu changes it).
func apply_comfort() -> void:
	var g := comfort.grain if comfort else 1.0
	mat.set_shader_parameter("grain", resting_grain * g)
	mat.set_shader_parameter("shadow_noise", shadow_noise)


## Fade the world's colour to `value` over `time` seconds.
func fade_saturation(value: float, time := 2.5) -> Tween:
	var tw := create_tween()
	tw.tween_property(self, "world_saturation", value, time)
	return tw


func tween_shader(param: String, value: float, time: float) -> Tween:
	var tw := create_tween()
	tw.tween_property(mat, "shader_parameter/" + param, value, time)
	return tw


## A memory comes back: a warm flash that settles slightly warmer than before.
func warm_flash() -> void:
	var tw := create_tween()
	tw.tween_property(mat, "shader_parameter/warmth", 0.6, 0.6)
	tw.tween_property(mat, "shader_parameter/warmth", -0.1, 3.0)


## A hit: vignette and colour fringe spike, then relax.
func pulse(vignette: float, aberration: float) -> void:
	var tw := create_tween().set_parallel(true)
	tw.tween_property(mat, "shader_parameter/vignette", vignette, 0.08)
	tw.tween_property(mat, "shader_parameter/aberration", aberration, 0.08)
	tw.chain().tween_interval(0.1)
	tw.chain().tween_property(mat, "shader_parameter/vignette", resting_vignette, 1.2)
	tw.parallel().tween_property(mat, "shader_parameter/aberration", resting_aberration, 1.2)


func set_vignette(value: float, time := 0.6) -> void:
	tween_shader("vignette", value, time)


func reset_vignette(time := 0.6) -> void:
	tween_shader("vignette", resting_vignette, time)


func _process(delta: float) -> void:
	var cam := get_viewport().get_camera_3d()
	_update_lens(cam, delta)
	if not cam:
		return
	_update_faces(cam)


## Lens on for the player camera, softer in cutscenes, off for any other camera.
func _update_lens(cam: Camera3D, delta: float) -> void:
	var target := 0.0
	var player_cam := cam as PlayerCamera
	if player_cam:
		target = cinematic_lens_scale if player_cam.cinematic else 1.0
		if comfort:
			target *= comfort.lens
	_lens = move_toward(_lens, target, delta * lens_fade_speed)
	mat.set_shader_parameter("lens_k1", lens_bend * _lens)
	mat.set_shader_parameter("lens_k2", lens_bend_edges * _lens)
	mat.set_shader_parameter("lens_fringe", lens_fringe * _lens)


## Pixelate the memory figures' faces (nodes in the "memory_face" group).
## Positions are flat-screen pixels; the shader bends first, then tests them, so the
## mosaics stay on the faces with the lens on.
func _update_faces(cam: Camera3D) -> void:
	var faces: Array = []
	for f in get_tree().get_nodes_in_group("memory_face"):
		var face := f as Node3D
		if not face.is_visible_in_tree():
			continue
		var p := face.global_position
		if cam.is_position_behind(p) or cam.global_position.distance_to(p) > face_blur_distance:
			continue
		# hidden behind a wall? then there's nothing to pixelate
		var hit := face.get_world_3d().direct_space_state.intersect_ray(PhysicsRayQueryParameters3D.create(cam.global_position, p))
		if not hit.is_empty() and (hit.position as Vector3).distance_to(p) > 0.35:
			continue
		var c := cam.unproject_position(p)
		var edge := cam.unproject_position(p + cam.global_transform.basis.x * 0.13)
		faces.append(Vector4(c.x, c.y, c.distance_to(edge), 1.0))
		if faces.size() == 4:
			break
	while faces.size() < 4:
		faces.append(Vector4.ZERO)
	mat.set_shader_parameter("faces", faces)
	mat.set_shader_parameter("face_count", 4)
```

Postcondition: the file contains `_update_lens`, `_update_faces` and `apply_comfort`.

## Rules learned from the research (keep them)
- Camera MOTION sells the effect more than any filter; filters alone read as "a filter".
- Never make distortion/blur scale with mouse speed (documented nausea cause, itch.io "Fractured Mind").
- Never add input lag to mouse look; sway goes on top of look, never replaces it (Game Accessibility Guidelines).
- Rotational shake > translational; smooth noise (FastNoiseLite) > randf white noise.
- Overscan or crop the lens so edges never smear/black out; bend AFTER deciding what screen pixel
  maps where (face mosaics are tested in flat space after the bend).
- Any screen-space distortion breaks mouse picking via `project_ray_origin` → lens must be off for
  cameras that use the mouse (drawing puzzle).
- Ship every effect with a 0 setting (Xbox Accessibility Guideline 117).

- Unrecord realism: photogrammetry + fisheye + shake + exposure lag: https://guided.news/en/special/unrecord-why-it-is-not-fake/
- UE bodycam plugin design (spring sub-stepping, overscan before fisheye): https://forums.unrealengine.com/t/matify-games-bodycam-camera-system-true-first-person-multiplayer-v1-0-0/2848471
